## About Me

I'm a Software Development student interested in the engineering behind modern applications — especially backend development, databases, application architecture and the way different parts of a system work together.

I enjoy working with application logic, structuring data and understanding how software moves from an idea to a maintainable solution. While backend development and databases are my main areas of interest, I also enjoy exploring UX/UI and frontend development to better understand the complete product-building process.

My goal is to continue developing strong software engineering foundations while building projects that challenge me to think about architecture, scalability, usability and clean code.

- Focused on **Backend Development & Databases**
- Interested in **Software Architecture & System Design**
- Building applications with **ASP.NET Core & REST APIs**
- Exploring **UX/UI and Full Stack Development**
- Continuously improving through **hands-on projects**
